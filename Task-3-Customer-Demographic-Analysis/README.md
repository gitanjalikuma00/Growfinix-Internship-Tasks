# Task 3: Customer Demographic Analysis

## Internship
Growfinix Technology – Data Analytics Internship

## Objective
Perform Exploratory Data Analysis (EDA) on Tour Enquiries data to identify popular travel destinations and analyze customers based on age and income brackets.

## Technology Used
- Python
- Pandas
- Matplotlib

## Work Performed
- Loaded and inspected the Tour Enquiries CSV dataset
- Cleaned missing values
- Analyzed popular travel destinations
- Grouped customers by age
- Grouped customers by income bracket
- Created bar charts
- Created age and income histograms
- Exported cleaned data and analysis results

## Dataset
The project uses a Tour Enquiries CSV dataset containing customer demographic and travel enquiry information.

## Output
The analysis generates:
- Top destination analysis
- Age group analysis
- Income bracket analysis
- Popular destinations bar chart
- Age group bar chart
- Age distribution histogram
- Income distribution histogram
- Cleaned dataset

## Project Structure

Task-3-Customer-Demographic-Analysis/
- analysis.py
- data/
- output/

## Result
The analysis successfully identifies popular travel destinations and provides demographic insights based on customer age and income.
